# Determinants of Global Box Office Revenue

Static website and reproducible project files for the JSC370 final project on how production scale, audience engagement, genre, and franchise branding relate to box office revenue from 2010 to 2024.

## Website

https://koolgreg2009.github.io/JSC370-Final/

## Project Materials

- `index.html`: static GitHub Pages website
- `app.js`: client-side visualization logic
- `styles.css`: website styling
- `Final Report.pdf`: PDF version of the report
- `data/tmdb_movies_revenue_sample.csv`: cleaned movie-level dataset used by the website

## Data Source

- The Movie Database (TMDB) API: https://developer.themoviedb.org/reference/intro/getting-started

The cleaned dataset in `data/` was generated from TMDB API responses collected during the project workflow. The full analysis and modeling code live in the source project files used to prepare the final report.
